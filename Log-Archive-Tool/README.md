# Log Archive Tool

A simple Bash script that compresses a log directory into a timestamped `.tar.gz` archive.

## Features

- Archive any log directory
- Timestamped archive names
- Error handling for invalid directories
- Gzip compression

## Usage

- Make it Executable first 
  
  chmod +x log-archive.sh

- To Run it 

```bash
./log-archive.sh logs
```

## Example Output

```
=====================================
 Archive created successfully!
 Archive Name : logs_2026-08-07_15-02-31.tar.gz
 Saved To     : archives/
=====================================
```
